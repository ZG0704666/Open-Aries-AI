# 安全边界与风险说明

> 本项目具备桌面自动化能力。请在受控环境中使用，并遵循最小权限原则。

## 1. 高风险能力

以下动作可能造成不可逆影响：

- `Execute`（命令执行）
- `FileWrite` / `FileAppend`（文件修改）
- `FileDelete`（删除）
- `FileRun`（执行本地文件）

当前策略：

- 默认关闭；
- 需要显式开启；
- 执行前二次确认。

## 2. 密钥与配置

- 新写入采用 Windows DPAPI 加密（用户本机上下文绑定）。
- 历史旧格式支持读取兼容，建议逐步迁移。

## 3. 企业环境建议

- 默认禁用 `Execute` 与 `FileRun`。
- 将 Agent 运行账户限制在低权限用户。
- 仅允许访问受控目录（白名单目录策略，后续建议实现）。
- 使用代理层或网关限制可访问的模型接口。

## 4. 已知风险

- 仍依赖模型输出质量，存在误操作风险。
- 当前命令防护仍有黑名单成分，需逐步转向白名单模板。
- 平台能力高度依赖 Windows API，跨平台隔离能力有限。
