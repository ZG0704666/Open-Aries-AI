## 这个项目到底是什么？

Open-Aries-AI 是一个 **Windows 桌面智能自动化 Agent**：

- 通过截图理解当前屏幕；
- 调用多模型（OpenAI 兼容 API）进行决策；
- 执行点击、输入、应用启动、文件读写、命令执行等动作；
- 将执行结果反馈给模型并迭代。

它是一个 **可执行程序（`aries_agent.exe`）+ 源码工程**，既可直接运行，也可从源码构建。
